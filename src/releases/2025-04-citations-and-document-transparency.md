---
title: Citations and Document Transparency
date: 2025-04-25
tag: Tools
---

When the assistant draws on workspace documents, every reference is now traceable. Responses include inline citations — clickable links to the exact passage the agent used. Click one and you go straight to the source material.

Every file also shows its indexing status — processed, currently indexing, or pending — so you always know when a document is part of the agent's searchable knowledge base. No more guessing whether the AI has access to a file or where it got its information.
