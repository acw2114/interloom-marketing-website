---
title: Activity Trail
date: 2026-02-22
tag: Security
---

Every action taken within a procedure — stage transitions, tool executions, agent decisions — is now logged in a comprehensive activity trail. This gives teams full auditability over their processes: who did what, when, and at which stage.

For regulated industries or teams that need to demonstrate process compliance, this provides the documentation layer that turns informal workflows into auditable, defensible processes.

The activity log is available directly within the task view, so reviewing the history of a case requires no extra navigation.
