![Activity trail](/images/releases/activity-trail.png)

Every action taken within a procedure — stage transitions, tool executions, agent decisions — is now logged in a comprehensive activity trail. Full auditability over your processes: who did what, when, and at which stage.

For regulated industries or teams that need to demonstrate process compliance, this provides the documentation layer that turns informal workflows into auditable, defensible processes. The activity log is available directly in the task view, so reviewing the history of a case requires no extra navigation.
