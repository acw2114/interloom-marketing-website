---
title: External API Access
date: 2026-01-14
tag: Tools
---

The agent can now make HTTP requests and GraphQL calls to external services on your behalf. This means it can query REST APIs, pull data from GraphQL endpoints, and interact with external platforms as part of its workflow — whether that's fetching data from an internal tool, checking the status of an order in a third-party system, or pushing updates to an external service.

Combined with MCP integrations, this positions the agent as a true integration layer that can reach into the systems your team depends on, without requiring custom development.
