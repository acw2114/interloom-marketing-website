title: Structured File Processing
date: 2026-02-22
tag: Tools
---

Your AI assistant can now read and analyze the contents of uploaded files directly within a conversation. Upload a spreadsheet, CSV, JSON file, or PDF, and the agent parses it into structured data it can reason about — returning column types, row counts, and a formatted preview of the contents.

For Excel files, the agent can navigate between sheets. For PDFs, it renders page-by-page previews and extracts content for analysis.

This means you can ask questions about a dataset, cross-reference a spreadsheet against case details, or pull specific figures from a report without ever leaving the thread. The tool handles files up to 100MB and supports CSV, TSV, XLS, XLSX, JSON, JSONL, and PDF formats.

For teams whose workflows involve reviewing documents, validating data, or extracting information from files that arrive as attachments, this turns the AI assistant from a conversational tool into one that can actively work with your data.
