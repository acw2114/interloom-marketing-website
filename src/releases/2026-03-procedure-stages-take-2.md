We're reworking how stages run so you can follow case progression without needing to understand the internals. Planned capabilities:

- Optional sequential stages and parallel subtasks
- Agent invocation status tracking
- Manual stage controls — skip, complete, block, reopen
- Automatic subtask summaries in the main thread
