---
title: File Viewer
date: 2025-06-30
tag: UX
---

Files can now be opened and viewed directly within Interloom, without downloading them or switching to another application. A new file panel supports PDFs with page navigation, images with inline preview, email files (.eml) with formatted rendering, and a dedicated view for notes with attachments.

Open any file from a conversation thread, a task's files panel, or search results — and it appears in a side panel alongside your current work. Every file also displays its metadata and properties in a consistent format.

For document-heavy workflows, this means reviewing a contract, checking an email attachment, or referencing an image happens in context, right next to the conversation where it's relevant. You stay in the flow of work instead of bouncing between tabs.
